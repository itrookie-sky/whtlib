## 约束

- 不改变既有公开接口、字段类型、加密算法、TTL、重试或资源管理行为。
- 现有 Err 标识只迁移声明，不改变其名称或现有匹配语义；标准库、Redis/Kafka 原生错误继续可识别。
- 不为每条校验文案新增导出变量，详细信息放入包装上下文。
- 错误构造和包装助手放入各包 error.go，业务代码直接复用。
- 不新增或修改测试文件，不运行整个仓库集成测试，不连接外部数据库、Redis 或 Kafka。
