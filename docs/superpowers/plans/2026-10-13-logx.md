# logx Implementation Plan

**Goal:** 实现基于 slog 的 ctx 日志和可配置文件轮转。

**Architecture:** Logger 构造 Record，自定义 Handler 编码有序 context JSON 并串行输出，FileWriter 独立管理文件。派生 Logger 共享生命周期。

**Tech Stack:** Go 1.26.3 标准库。

**Spec:** ../specs/2026-10-13-logx-design.md

## Global Constraints

- 包名 logx，路径 extension/logx，不引入第三方依赖。
- ctx 必传，traceId 在 JSON 首位；Skip 不改变原实例。
- FileWriter 默认保留归档 24h，大小、周期和保留时间均可配置。
- 沿用当前工作区，完成后提交并推送；新增测试遵循用户授权。

## 执行步骤

- [x] 创建 options.go、context.go、caller.go：校验可比较 key；有序编码；解析业务调用位置。
- [x] 创建 handler.go、logx.go：实现 slog.Handler 的属性分组和共享写锁；输出方法无返回值，内部 Handler 保留错误处理；派生实例共享关闭状态。
- [x] 创建 file_writer.go、rotate.go：提供 NewFileWriter、Write、Rotate、Cleanup、Sync、Close；默认配置；后台维护和精确匹配归档清理。
- [x] 更新 README 和设计文档，说明配置、生命周期、默认值和限制。
- [x] 执行 go build、go vet、gofmt 检查；如用户授权则新增并运行模块测试和 race 检查。
- [x] 检查差异，仅提交相关文件并推送 origin/main。
